1. USB 키보드 연결

CH57x-1과 CH57x-2 디자인은 화면 오른쪽 위에서 장치 연결 없이도 선택해 볼 수 있습니다. 실제 USB 연결 시 확인된 장치 프로토콜에 맞는 화면이 자동 선택됩니다. 화면 선택은 통신 프로토콜을 변경하지 않으며, 호환성이 확인되지 않은 장치로는 설정을 보내지 않습니다.

연결되지 않음호환 장치 미연결

적절한 CH57x 장치가 연결되지 않았습니다. USB 장치를 연결하면 CH57x-1 / CH57x-2 호환성을 확인합니다.

Windows에 보이는 MI_01은 일반 키보드 인터페이스일 수 있습니다. 설정 통신은 FF00:0001의 제조사 전용 HID 인터페이스가 필요합니다. USB ID는 컴퓨터가 아닌 장치에서 보고하는 값입니다.

Chrome/Edge의 http://localhost 또는 HTTPS에서 열어야 합니다. 제조사 설정 프로그램이 실행 중이라면 먼저 종료하세요.

Bluetooth 9Keys+3Knobs · 05AC:022C · 프로토콜 연구 화면

읽기 전용 진단 / 로컬 편집 시제품 — 제조사 MINI KeyBoard 프로그램 사용 사실은 확인했지만, 해당 모델의 설정 통신 경로와 HID Report 구조는 미확인입니다. 이 패널은 키 설정을 실제 장치로 전송하지 않습니다. 일반 Bluetooth HID 키보드 서비스(0x1812)는 브라우저에서 접근이 제한될 수 있습니다.

일반 Bluetooth 키보드 HID만 있는 경우 전송 불가. USB FF00:0001, Report ID 3 확인 후에만 활성화합니다. 동의 후 연결 버튼으로 다시 연결하세요.
진단 전 · 05AC:022C는 아직 설정용 인터페이스가 확인되지 않았습니다.

9Keys + 3Knobs 구성 미리보기

2. 기존 설정 읽기

장치 선택 창의 제품명은 브라우저/USB 펌웨어에서 제공하므로 바꿀 수 없습니다. 연결 후 웹페이지에는 CH57x 키/노브 개수 및 USB ID를 표시합니다. 처음 연결할 때 레이어 1을 읽고 물리 키와 노브 수에 맞는 편집 버튼을 생성합니다. 설정을 모두 읽어야 쓰기 기능이 활성화됩니다. 레이어 2/3의 실제 전환은 제품 펌웨어에 따라 다릅니다.

3. 선택한 입력 변경

KEY 1을 편집합니다. 아래 값은 새로운 설정이며, 기존 설정을 읽은 경우 각 입력을 선택하면 아래 편집기에 자동으로 표시됩니다.

같은 Step의 왼쪽/오른쪽 수정키는 일반 키와 동시에 입력됩니다. 각 Step은 위에서 아래 순서로 실행됩니다.
선택 박스와 직접 입력창은 서로 연동됩니다. 키를 선택하면 해당 Step이 즉시 갱신됩니다. 기존처럼 일반 키 이름을 직접 입력할 수도 있습니다.한 Step에는 조합키 여러 개와 일반 키 하나를 지정할 수 있습니다. Ctrl만 단독으로 누르는 입력은 현재 CH57x-1 프로토콜에서 지원이 확인되지 않았습니다.
지연은 0~6000ms, 1ms 단위입니다. 이 모델은 각 Step에 독립된 지연값을 저장하지 못하고 매크로 전체에 공통 지연값만 지원합니다. 서로 다른 값이 있으면 저장을 차단합니다. 장치의 기존 지연값은 읽기로 확인할 수 없습니다.
위 버튼으로 편집하면 자동 갱신됩니다. 이 텍스트를 직접 편집하면 Step 목록에도 반영됩니다.

미리보기를 만든 뒤 내용을 확인하고 저장하세요.

v7.8.3: 기기가 보고한 각 KEY 및 노브 슬롯을 정상적으로 읽은 경우에만 저장할 수 있습니다. 읽기 응답이 누락되거나 충돌한 슬롯은 자동으로 저장이 차단됩니다. 저장 시 해당 슬롯의 원래 설정이 덮어써집니다. 먼저 JSON 백업을 권장합니다. 읽어온 설정과 저장 후 다시 읽은 설정을 비교합니다. 처음에는 하나의 키부터 테스트하세요.

2. CH57x-2 · 키·노브 설정

CH57x-2 전송 형식 실물 적용 확인 · 6Keys+1Knob 장치에서 키·노브 설정 변경이 확인되었습니다. 다른 구성에서는 추정 슬롯 번호를 사용하므로 전송 전 확인이 필요하며 의도하지 않은 입력이 덮어써질 수 있습니다. 이 기기는 기존 설정 읽기를 지원하지 않아 편집값 JSON 백업만 가능합니다. 기기 펌웨어가 다른 경우 적용되지 않을 수 있습니다. 장치 초기화/펌웨어 명령은 전송하지 않습니다.

6Keys+1Knob만 슬롯 매핑을 실물 검증했습니다. 다른 구성은 추정 슬롯으로 시험 전송할 수 있습니다.

3. 선택한 입력의 동작 설정

KEY 1 · 레이어 1

동작을 먼저 선택하면 아래에 해당 편집기가 표시됩니다. 선택한 키·노브의 편집값은 유지됩니다.
예: a, enter, ctrl+c, alt+f4. 각 Step은 기존 키 코드 목록을 사용합니다. 키 코드가 지원되지 않으면 미리보기에서 오류가 표시됩니다.
주의: CH57x-2의 Step별 지연시간 전송 형식은 검증되지 않았습니다. ms 값은 편집·JSON 백업에만 기록되고, 기기에 전송하지 않습니다. 각 Step은 현재 확인된 명령대로 전송됩니다.

설정 내용은 먼저 이 웹페이지 안에서만 변경됩니다. 아래 '8890 설정 전송'을 누르기 전에는 실제 기기에 아무것도 저장되지 않습니다. 기존 설정 읽기는 지원되지 않습니다.

장치를 연결하면 사용 가능합니다.

4. LED 조명 설정 · 1189:8890 (실물 검증된 4개 효과)

검증된 B0 08 00~03 효과만 전송합니다. 1189:8840/8842 기반 색상 코드, B0 18 시험, 개별 LED 색상 저장은 제거했습니다. 이 장치는 LED 색상·위치를 자동으로 읽을 수 없습니다.

LED 효과 명령은 실물에서 작동 확인. 색상·개별 LED 주소는 미확인.

연결이 되지 않으면 이 로그를 복사해 전달하면 통신 문제를 좁힐 수 있습니다. 민감한 내용이 아니라 USB 응답 코드와 설정 기록만 남기며 자동으로 업로드하지 않습니다.
